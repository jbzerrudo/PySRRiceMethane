# PySRRiceMethane

Symbolic regression of rice paddy CH4 fluxes across three eddy-covariance sites (PH-IR, JP-MSE, SK-CRK) using PySR.

## Repository contents
- `UseScript/` - analysis and pipeline scripts. `PySR7v2.py` is the main PySR pipeline (internal v6.3).

## Data
Input flux data and full model-run outputs are archived separately (DOI link to be added) and are not stored in this repository.
